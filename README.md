# 🕹️ Unity Obstacle Course

A simple Unity obstacle course game prototype.

## 🔽 How to Play

1. [Download the latest release](https://github.com/andrewbrase/unity_obstacle_course/releases)
2. Extract the `.zip` file to your preferred location
3. Run `udemy_obstacle_course.exe` to launch the game
4. Press `Alt + F4` to close the game
